MD Studio – Privacy Policy

Effective 16 November 2026

MD Studio is a Chrome extension for reading and editing Markdown files. It does not collect, transmit, sell or share personal data. It has no servers, accounts, analytics or advertising.

What is stored on your device

  • The documents you have open in a tab, including unsaved text, in that tab's session storage, so a reload of the tab brings them back. It is not shared with other tabs and is removed when the tab closes.
  • The most recent session that had documents (including unsaved text), in the extension's local storage, so the welcome screen of an empty tab can offer to restore it. Choosing Dismiss there erases it; it is replaced by the next session that has documents.
  • Handles to files you opened or saved, and a short list of recent files, in the extension's IndexedDB. Chrome asks for your permission again when a file needs to be re-opened for writing.
  • Interface preferences such as theme, full-width mode, the outline panel, line numbers, word wrap and the size of the editor and preview.

This data never leaves your device. You can remove it by removing the extension or clearing its site data.

The web version

MD Studio is also available as a web page. It runs entirely in your browser tab and makes no network requests of its own. Because every project hosted under a github.io account shares one browser storage area, the web version keeps your open documents in session storage (this tab only, gone when it closes) instead of local storage. Files you open or drop stay on your device; where the browser cannot write files in place, Save downloads a copy.

Network access

  • The extension fetches a Markdown file by URL only when you open that URL in it (for example by clicking the toolbar icon on a .md page). For http/https sites, Chrome asks you to grant access to that single origin first.
  • If a document references an image by http/https URL, Chrome loads that image to render the preview, which contacts the image's host. This is the same as viewing the document in a browser. The extension does not send your content anywhere.
  • The extension makes no other network requests.

Permissions

  • activeTab: to read the current tab's URL when you click the toolbar icon.
  • webNavigation and file access: to open local .md files in the editor when you navigate to them. Local files are read only when you open them.
  • Optional website access: requested per site, only when you choose to open a Markdown URL from it.

Third parties

No data is shared with third parties. All code, including the open-source libraries marked, DOMPurify and highlight.js, is bundled in the extension. No remote code is loaded.
